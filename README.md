# Tinker

**Tinker** is a high-performance desktop application designed for the modern maker, learner, and creative professional. It serves as a digital companion for complex, long-term projects—what we call "Workbenches"—bridging the gap between messy experimentation and structured skill development.

## Key Features

- **The Shop Concept:** Organize your creative life into specialized environments like Woodworking, Coding, or Electronics.
- **Structured Documentation:** Capture your process using five atomic units: Observations, Attempts, References, Questions, and Breakthroughs.
- **Constellation View:** An interactive 2D graph that visualizes the invisible threads connecting your projects across different domains.
- **The Scar Map:** Visualize your "failed" attempts as data points, mapping out where you encountered friction and growth.
- **Skill Portfolios:** Automatically aggregate your activity into a comprehensive overview of your professional and creative mastery.
- **Premium Aesthetics:** A fluid, glassmorphic interface designed for 60fps performance and a premium feel.

## How to Test Use

To run Tinker locally for testing, follow these steps:

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/) (comes with Node.js)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/AlexSai121/Tinker.git
   cd Tinker
   ```

2. **Install dependencies:**
   ```bash
   cd tinker
   npm install
   ```

3. **Run the application:**
   ```bash
   npm run dev
   ```

The application will start in development mode. You can begin by creating your first **Shop** from the sidebar and adding a **Workbench** to start documenting your progress.

## Technology Stack
- **Framework:** React + Vite
- **Shell:** Electron
- **Database:** SQLite (via Drizzle ORM)
- **Styling:** Tailwind CSS 4.0
- **Animations:** Framer Motion
